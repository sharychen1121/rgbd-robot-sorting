# 本版本真实验证记录

以下结果均来自实际运行，用于验证工程链路。样本量小，不构成“新方法优于原方法”或随机场景普遍可靠的结论。未运行的正式实验没有预填分数。

## 本地环境与自动检查

Windows、Python 3.11.9、PyBullet 3.2.7、Ultralytics 8.4.212、CPU PyTorch 2.15.0、NumPy 2.4.6。精确依赖快照见根目录 `requirements-cpu-lock.txt`。显卡渲染与 CUDA 训练分别检查，本次训练使用 CPU。

已通过核心测试，覆盖：米制深度反投影、负/越界 bbox、概率/缺失掩码、真值隔离、场景冻结、合成标签、移动后的 YAML 路径、字节哈希、误分拣评分、配对场景校验、缺测时间、碰撞与关节限制、实际错误类别搬运。运行方法：

```powershell
python -m unittest discover -s tests -v
```

其中实际误分类回归测试把 cube 预测成 box，要求机器人真实放到 C 区并评分为 `mis_sorted`，防止使用真值纠错。CI 使用相同核心测试；CI 是否通过应查看仓库实际运行状态，不能把本地成功当作云端已成功。

## 机械臂参考流程

完整源记录保存于 `examples/verification/fixed-reference` 和 `random-reference`。

| 测试 | oracle | HSV + RGB-D | 说明 |
|---|---|---|---|
| 固定三物体演示 | 3/3 物体正确 | 3/3 物体正确 | 单场功能验证 |
| 标准随机 seeds 43–45 | 3/3 场、9/9 物体 | 3/3 场、9/9 物体 | 仅三个冻结场景，未筛场 |

每次放置均有提起与目的区域支撑接触检查。随机 HSV 记录的 36 次拒绝属于额外颜色候选的几何关联失败，不能当作 36 个不同物体或检测错误率。oracle 是真实位姿诊断，不是学习模型分数。

计时来自共享 CPU，负载不同；这里不比较方法速度。`initialization_s` 是控制器构建时间，模型冷加载和预热另存在 metadata；任务总时间包含相机采集、规划与运动。

## 深度学习链路

首次功能试验真实生成 90 个独立 320×240 场景，随机颜色和光照，含 14 个负样本；62/13/15 张划分。YOLO26n-seg 从官方预训练权重微调 5 epochs，在 15 张测试图片、39 个物体上得到：

| 指标 | 五轮 pilot 实测 |
|---|---:|
| box mAP50 | 0.265 |
| mask mAP50 | 0.193 |
| mask mAP50–95 | 0.0614 |

checkpoint 重载、预测掩码、RGB-D 定位均已真实调用，运行相机没有仿真 segmentation 输入。但该模型明显训练不足，低阈值预测有重复和误分类，不能作为正式模型或“学习分支分拣成功”证明。

完整参数、权重哈希、逐候选坐标与图像见 `examples/verification/learning-smoke.json`、`learning-smoke.md` 和叠加 PNG。该早期数据由 schema 1 生成，验证器明确提示缺少旧版检测标签哈希；仓库当前生成代码已升级为可移动路径、双任务哈希的 schema 2。

追加阶段从五轮模型初始化新优化器，最多计划 25 轮，实际在 20 轮早停，选择该阶段第 12 轮权重；不是从头连续训练 30 轮。保留图片集复测的 box mAP50 为 0.6912、mask mAP50 为 0.5079。该集合已在初期检查过，因此不作为未接触的最终测试集。三张全新正样本场景分别有 2、4、3 个候选，仍有漏检和重复；新增空场景零候选。

随机颜色 seed241118 的完整任务实测：同一 checkpoint、同一场景与控制器，`yolo_box` 和 `yolo_mask` 均正确放置 3/3，`hybrid` 为 0/3。Hybrid 内部固定类别颜色规则滤掉了全部中等置信度预测，完整证据保存在 `examples/verification/learned-sorting`。两种学习定位都成功，不能从这一个场景宣称掩码优于框。

已将实际验收用的 checkpoint 放入 `examples/checkpoints/yolo26-pilot.pt`，约 6.6 MB，SHA-256 为 `dd22994db1c3bc4cac73b816087bb0d11ec5d930653853cd1018a173b0fd04ac`。下载仓库后可直接重放学习演示。正式结论仍需要新版本数据、验证集调参、多种子训练，以及至少 30 个配对场景。
