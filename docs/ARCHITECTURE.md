# 模块、数据流与真值边界

`types.py` 约定 RGB 为 uint8，深度为米制光轴距离，bbox 按 `(left, top, right, bottom)` 排列，位姿为世界坐标米和弧度。相机使用真实 4×4 OpenGL 视图/投影矩阵。

| 模块 | 责任 |
|---|---|
| `sim.py` | 可复现场景、独立物理连接、TinyRenderer 同帧 RGB/深度；真值显式开启 |
| `dataset.py` | 自动标注、负样本、场景划分、双任务标签、哈希校验与安全输出 |
| `perception.py` | 本地 YOLO 推理、HSV/Hybrid、框或预测掩码区域的 RGB-D 反投影 |
| `training.py` | 明确下载许可、训练/验证参数、checkpoint 与数据来源记录 |
| `execution.py` | 候选关联、抓取姿态预检、多姿态搜索、动作和最终评分 |
| `evaluation.py` | 场景指纹、配对结果包、准确计数、CSV/JSON/图表 |
| `cli.py` | 串联命令、权重与类名预检查、加载预热、不可静默混合的实验 |

## 运行时信息

学习分支读取 `Frame.rgb`、`Frame.depth_m` 和标定信息，`Frame.segmentation=None`。深度筛选对框/掩码使用同一规则，不按真实物体 ID、位置或类别纠正结果。

执行器为了实现虚拟约束抓取，按预测位置与物理 AABB 的接近程度选择碰撞物体。不用真实类别过滤；预测类别决定目标区。这个几何检查是已知仿真后端的一部分，也可能拒绝本可用的候选，须计入失败。安全预检使用所有碰撞几何和关节限位。

执行后，用真实类别与实际区域判断正确或误分拣。测试故意把 cube 预测成 box，要求它真实放到 C 区并记录 `mis_sorted`，防止真值替模型纠错。

`oracle` 明确调用真实位姿，只用于分析后端约束。训练数据生成可读取仿真分割缓冲；评价可读取真值。这两种权限不能被推理复用。

## 动作与失败

预抓取、下降、提起、源上方、目的上方、释放各段先做 IK 和碰撞预检，再以电机位置控制步进执行。多 IK 起点和等价角归一化改善可行解搜索，仍遵守原 URDF 限位。临时 FK/碰撞状态检查会恢复状态，不用于瞬移搬运物体。

候选只有在可行性检查成功后才参与去重，避免首个坏候选屏蔽后续备选。优先尝试多个抓取朝向，并保留各阶段拒绝原因；运动或物理提起失败后安全保持，不盲目在未知载荷状态继续。

固定约束的建立检查末端与物体距离；提起要求物体离桌；释放后检查物体与目标垫真实接触、边界包含与稳定性。这些是仿真搬运条件，不等价于真实夹爪的力闭合或抓取稳定性。

## 输出边界

`progress.jsonl` 是中间记录。`results.jsonl`、CSV、汇总和最后写入的 `metadata.json` 构成完成的结果包，后者校验源文件。默认防覆盖，配对汇总拒绝场景集合不等、对象数不一致或重复轮次。零次有效观测不通过伪造推理次数来计算延迟，缺测时间保留 null。

逐轮 `initialization_s` 仅表示控制器设置；模型冷加载与一次预热在 `metadata.models`，并被同一 checkpoint 的消融分支共用。`perception_s` 是预测器实际调用时间的累计值，RGB-D 采集仅计入轮次 `total_s`，场景构建不计入任务时间。
